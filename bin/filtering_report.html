    Apply it in the pipeline

    Rerun the pipeline with the same command, adding:

    -resume --metacell_selection metacell_selection.json

    Only the filtering step runs. The filtered matrices of each sample are written to metacell_filtering/<sample>/<sample>_final/.

Continue from an earlier selection

Loading a selection restores the settings of the samples it covers, and marks them applied.
